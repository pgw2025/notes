# 笔记热力图功能验收清单

- 状态：已实施（代码级验证通过，交互项待手动验收）
- 日期：2026-09-16
- 关联文档：[plan.md](./plan.md)

> 实施调整：数据源由原方案的「IndexedDB 本地查询」改为复用服务端
> `/notes/timeline` 接口（按 `fromDate` 过滤 + 按 `UpdatedAt.Date` 分组计数）。
> 当前代码库无本地 IndexedDB 数据层（纯服务端获取），热力图与时间线列表
> 共用同一数据口径，点击格子筛选出的日期与列表分组完全一致。
> 原方案中依赖 IndexedDB 的条目已标注「不适用」。

## 一、功能验收

- [x] 热力图展示近 12 个月、7 行（周一~周日）× 53 周网格
- [x] 统计口径为「当天编辑过的笔记数」（服务端按 `UpdatedAt.Date` 对笔记分组去重计数，每篇每天只计 1 次）
- [x] 悬停/键盘聚焦格子显示 tooltip：日期、篇数、强度级别；tooltip 随指针移动并钳位在卡片内
- [x] 点击图例色块高亮/锁定对应级别格子（hover 预览，点击锁定，再点取消；其他级别弱化）
- [x] 点击非空格子，Timeline 筛选出当天笔记列表；再次点击同一格取消筛选
- [x] 空数据时显示空状态提示，不渲染空矩阵
- [x] 数据刷新：Timeline 未启用 keep-alive，每次进入页面重新挂载触发 `onMounted(load)` 重新拉取（原方案的 `localdata:changed` 事件在当前代码库不存在，未实现）

## 二、数据正确性

- [x] 日期口径与服务端一致：热力图网格与服务端分组均按 UTC 日期计算，点击格子筛选的日期与时间线列表分组严格对应，不串天
- [ ] 未同步的本地修改计入热力图 —— 不适用（当前无本地优先存储，数据源为服务端）
- [x] 已删除笔记不参与统计（服务端仅返回现存笔记）
- [x] 一天内多次编辑同一篇笔记只计 1 次（笔记按最新 `UpdatedAt` 分组，每天一个分组计数）
- [x] 新建笔记当天即有热度（`UpdatedAt` 为当天）
- [x] 请求失败/离线时显示错误提示「热力图加载失败」，不影响时间线列表展示

## 三、性能

- [ ] 查询走 updatedAt 索引范围查询，不出现全表遍历 —— 不适用（聚合在服务端完成，复用现有 timeline 端点）
- [x] 千级笔记量下单次聚合毫秒级完成，无卡顿（服务端内存分组 + 前端构建 53×7 网格，均无循环内请求）
- [x] 聚合时不读取 content 字段（前端仅消费 `date`/`noteCount`；服务端行为沿用现有 timeline 端点）

## 四、移动端与主题

- [x] 移动端横向滚动正常（`.heatmap-scroll` 横向滚动 + `-webkit-overflow-scrolling: touch`），页面底部有 tabbar 避让
- [x] 窄屏 tooltip 不溢出屏外（绝对定位 + 钳位 + 靠近顶部时自动翻转到下方）
- [x] 深色/浅色主题切换后色阶清晰可辨（CSS 变量分别定义两套色阶，`body.dark` 下覆盖）

## 五、回归

- [x] Timeline 原有按日期分组列表功能不受影响（热力图仅新增顶部卡片，构建通过）
- [x] 热力图筛选与时间线自带筛选不冲突（`onHeatmapSelect` 只覆盖日期区间与快捷区间，分类/标签/关键词筛选保留）
- [ ] 离线状态下热力图可正常展示本地数据 —— 不适用（无本地数据层；离线时显示错误提示）

> 剩余手动验收项：浏览器实测 hover tooltip 定位、图例锁定视觉、移动端横滑、
> 深/浅主题切换、点击格子联动列表。
